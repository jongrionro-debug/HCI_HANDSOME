# LUMI · HCI_HANDSOME

LUMI는 장·단기 메모리와 이미지 선택·대화를 활용해 사용자의 평소 취향과 현재 상황을 함께 반영하는 패션 추천 에이전트 연구 프로젝트다.

전체 설계·연구·실행 안내는 [통합 문서](docs/master.md), 개발 작업 규칙은 [AGENTS.md](AGENTS.md)에서 관리한다. 원문 기준과 현재 구현의 차이는 통합 문서의 해당 절에서 확인한다.

## 시작하기

- [Feature Map](docs/master.md#feature-map): 확정 사전, 원문 범위, 현재 실행 상태
- [연구와 평가](docs/master.md#연구와-평가): RQ·과제·측정·분석 기준
- [메모리 실행 계약](docs/master.md#메모리-실행-계약): 저장·조회·동의·근거 경계
- [개발자 관찰 도구](docs/master.md#개발자-관찰-도구): 로컬 관찰과 실제 모델 호출 범위
- [오프라인 실행과 검증](docs/master.md#오프라인-실행과-검증): 합성 입력·가상 adapter 기반 확인
- [다음 작업](docs/master.md#다음-작업): 미구현 범위와 이관 순서

작업 전에는 현재 체크아웃의 변경과 [master](docs/master.md)를 확인한다. 제품 상세·실행 명령·과거 설계는 master가 연결한 정본과 보관 자료를 기준으로 읽는다.
