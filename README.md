# HCI_HANDSOME

패션 추천 에이전트에 관한 HCI 연구와 이후의 시스템 작업을 준비하는 저장소입니다. 현재는 **연구·설계 준비 단계**입니다.

## 출발점

두 원본 문서는 일상적인 스타일 선호와 당일의 상황별 요구를 구분하고, 대화와 의상 이미지 비교를 통해 사용자의 의도를 파악하는 에이전트를 제안합니다. 이는 연구 방향과 예시 시나리오이며, 구현되거나 검증된 기능 목록은 아닙니다.

| 원본 | 담긴 내용 |
| --- | --- |
| [Scenario,Persona.pdf](Scenario,Persona.pdf) | 주제·가설, 페르소나 2명, 문제/상세 시나리오, 클레임 분석 |
| [ResearchObjective,SurveyStructure.pdf](ResearchObjective,SurveyStructure.pdf) | 연구 목표와 사전·사후 설문 구성 초안 |

## 현재 상태

- 정확한 시스템 구조와 데이터·추천 방식은 아직 결정하지 않았습니다.
- 제품 코드, 실행 환경, 프로토타입, 테스트가 없습니다.
- 설문 문항과 연구 절차는 확정되지 않았고 데이터 수집도 시작하지 않았습니다.
- 따라서 두 PDF의 시나리오나 설문 구성은 실제 동작 또는 연구 결과로 인용하지 않습니다.
