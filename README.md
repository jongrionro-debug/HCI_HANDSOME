# LUMI · HCI_HANDSOME

LUMI는 장·단기 메모리와 이미지 선택·대화를 활용해 사용자의 평소 취향과 현재 상황을 함께 반영하는 패션 추천 에이전트 연구 프로젝트다.

현재 구현·동작·실행·검증의 유일한 문서 정본은 [docs/master.md](docs/master.md)다. 과거 결정과 승인·대체 관계는 [docs/adr/](docs/adr/), 개발 작업 규칙은 [AGENTS.md](AGENTS.md)에서 관리한다. 연구 설계 원문인 중간보고서와 현재 구현의 범위도 master에서 구분한다.

## 시작하기

- [현재 구현](docs/master.md#현재-구현과-실행): 소비자 서비스와 구현 범위
- [메모리·Feature Map](docs/master.md#메모리-실행-계약): 근거·확인·동의·PI/FEA 계약
- [로컬 실행](docs/master.md#로컬-실행): 외부 DB·상품·이미지 설정과 시작 명령
- [검증](docs/master.md#오프라인-실행과-검증): 오프라인·브라우저 검사와 한계
- [연구와 평가](docs/master.md#연구와-평가): 보고서의 RQ·과제·측정 기준
- [다음 작업](docs/master.md#다음-작업): 미구현·미검증 범위

폐기한 설명 HTML·중복 문서는 Git 이력에서 확인한다. 실행 화면인 `src/stylemate_memory/consumer.html`·`inspector.html`은 앱 자원으로 유지한다.
