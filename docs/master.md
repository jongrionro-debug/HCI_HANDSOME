# 연구 기준

**확정일: 2026-10-04 · 확정 범위: 아래 문제 정의와 RQ1·RQ2**

이후 시스템 설계, 사용자 평가, 논문·포스터 작성은 이 문제 정의와 RQ를 기준으로 진행한다.

## 문제 정의

연구 대상은 **평소 스타일을 유지하면서 고객 미팅·발표 등 특정 상황에 맞게 코디를 조정해야 하는 사용자**다.

1. **일시적 요구와 지속적 취향의 혼동**: 결혼식용 정장 구매나 “오늘은 블레이저를 입고 싶지 않다”는 반응이 평소 취향으로 반영되면, 이후 추천이 사용자의 실제 취향에서 벗어날 수 있다. 사용자는 피드백을 이번 상황에만 적용할지, 기본 취향으로 저장할지 선택할 수 있어야 한다.
2. **취향과 상황 사이의 조율 부담**: 고객 미팅에 후디는 너무 편하고 정장은 과하게 느껴질 수 있다. 사용자는 검색 결과를 직접 비교하며 어떤 요소를 얼마나 바꿀지 결정해야 한다. 시스템은 유지할 취향과 상황 때문에 조정할 요소를 함께 다뤄야 한다.
3. **언어로 표현하기 어려운 스타일의 경계**: “단정하지만 정장 같지는 않게”라는 말만으로는 원하는 격식·실루엣을 특정하기 어렵다. 일정·이동량은 텍스트로 확인하고, 원하는 스타일의 정도는 코디 이미지 비교로 구체화할 필요가 있다.

## RQ

### RQ1. 기본·일시적 선호의 분리 관리와 사용자 주도성

**대화를 통해 점진적으로 구체화되는 사용자의 기본 선호와 현재 상황에서 형성되는 일시적 선호를 별도로 관리하고, 사용자가 이를 확인·수정할 수 있도록 하는 것이 추천 과정에 대한 사용자 주도성에 어떠한 영향을 미치는지 살펴본다.**

- 비교: 기본 선호와 일시적 선호를 구분하지 않는 방식 ↔ 두 선호를 별도로 관리하고 사용자가 확인·수정하는 방식.
- 평가: 사용자가 추천 조건을 확인·수정하고 추천 방향을 조정할 수 있다고 느끼는 정도.

### RQ2. 텍스트·이미지의 선택적 제공과 의도 표현

**에이전트가 사용자의 선호 조건을 파악하는 과정에서 추가 정보가 필요할 때, 텍스트 질문과 이미지 기반 선택을 선택적으로 제공하는 상호작용 방식이 사용자의 의도 표현 부담을 줄이고, 시스템이 자신의 의도를 이해하고 있다고 느끼는 정도를 높이는지 살펴본다.**

- 비교: 텍스트만 사용 / 텍스트·이미지를 고정 순서로 사용 / 추가 정보가 필요할 때 텍스트 질문과 이미지 기반 선택을 선택적으로 제공.
- 평가: 의도 표현 부담, 시스템이 자신의 의도를 이해한다고 느끼는 정도. 소요 시간·질문 수는 보조 지표로 기록.
