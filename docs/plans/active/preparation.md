# 연구·시스템 작업 준비 계획

상태: 미착수. 이 문서는 이후 작업의 순서를 정리한 **계획**이며, 확정된 시스템 명세나 수행된 연구 기록이 아닙니다. 출발 자료는 [시나리오·페르소나](../../../Scenario,Persona.pdf)와 [연구 목표·설문 구성](../../../ResearchObjective,SurveyStructure.pdf)입니다.

## 1. 연구 설계 확정

- [ ] 두 PDF의 가설과 연구 목표를 비교해 검증할 질문, 비교 조건, 측정 지표를 확정한다.
- [ ] 사전·사후 설문의 실제 문항, 척도, 순서와 분석 방식을 정한다. 현재 PDF에는 설문 영역만 제시되어 있다.
- [ ] 참여자 기준·모집·동의·진행 절차와 파일 보관/접근 정책을 정한다.
- [ ] 본 수집 전에 설문과 과제의 이해 가능성, 소요 시간, 기록 방식을 점검한다.

## 2. 시스템 설계 확정

- [ ] 두 시나리오에서 검증할 핵심 사용자 과업과 필요한 화면·상호작용을 정한다.
- [ ] 일상 선호와 세션 맥락의 구분, 사용자 확인·수정, 장기 선호 반영 조건을 정의한다.
  - 검토할 제안: [H1 기본 선호·상황 맥락 레이어 택사노미 초안](h1-layer-taxonomy.md). 확정 명세가 아니며, 후보 항목·값과 적용 범위 규칙을 제안한다.
- [ ] 텍스트 질문과 이미지 비교의 선택·중단 기준, 추천안과 설명의 범위를 정한다.
- [ ] 의상 이미지·상품 정보의 출처, 사용 권한, 갱신 및 추천 방식의 실현 가능성을 확인한다.
- [ ] 결정된 동작과 데이터 계약만 `docs/specs/`에 기록하고, 구현 범위를 정한다.

## 3. 구현·수집 착수 조건 점검

- [ ] 평가에 필요한 비교 조건과 프로토타입의 범위를 일치시킨다.
- [ ] 기능 시연과 데이터 기록을 시험하고, 개인 정보가 저장소에 들어오지 않는지 확인한다.
- [ ] 연구 절차와 보관 정책이 확정된 뒤에만 실제 참여자 데이터를 수집한다.

완료된 결정과 수행 기록은 이 체크리스트에만 묻어두지 않고 해당 명세·실험 문서 또는 실제 산출물에 남긴다.
